# 🐢 Terminal-Schule

Interaktive Lern-Website für die **Kommandozeile (Shell/Bash)** - Teil des
[Roboterarm-Workshops](https://github.com/ProfessorEngineergit/roboterarm).

- **Epische Geschichte** der CLI (Teletype → Unix → heute)
- Die **wichtigsten Befehle** mit Beispielen
- **Übungs-Trainer** mit 3 Stufen (simuliertes Terminal, Punkte, Belohnung)
- **Roboterarm-Spickzettel** (Installation, Server starten, …)

Komplett **offline-fähig** (PWA mit Service-Worker), kein Build, keine Abhängigkeiten -
reines HTML/CSS/JS.

## Live
GitHub Pages: `https://professorengineergit.github.io/roboterarm-learn/`
